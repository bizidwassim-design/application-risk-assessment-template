# Contributing

Thanks for helping improve this template! Contributions of any size are welcome: typo fixes, better scale
examples, additional control mappings, translations, or new sample scenarios.

## Ground rules

* **Fictional data only.** Never include real client names, employee names, e-mail addresses, credentials,
  internal system names or confidential incident details — even "anonymised" ones.
* **Keep it vendor-neutral and standards-based.** Cite clause/control identifiers accurately.
* **No macros or add-ins.** The workbook must stay a plain `.xlsx` that works in Excel, LibreOffice and Google Sheets.
* Be kind — see the [Code of Conduct](CODE_OF_CONDUCT.md).

## How the workbook is built

The `.xlsx` is generated by [`scripts/build_template.py`](scripts/build_template.py) (Python + `openpyxl`).
**Change the script, not the binary**, so that every modification is reviewable as a text diff.

```bash
pip install openpyxl
python scripts/build_template.py
```

## Making a change

1. Open an issue describing the problem or idea (optional for small fixes).
2. Fork the repository and create a branch (`fix/scale-wording`, `feat/new-sample-risk`).
3. Edit `scripts/build_template.py` and/or the Markdown docs.
4. Regenerate the workbook and open it. Check that:
   * no cell shows an error (`#REF!`, `#NAME?`, `#VALUE!`…);
   * formulas still handle empty rows (empty cells stay empty);
   * dropdowns, conditional formatting and the Dashboard counts still work;
   * text is in Arial, inputs are blue, formulas are black on grey.
5. Commit both the script change **and** the regenerated `.xlsx`.
6. Open a pull request describing what changed and why.

## Style notes

* Font: Arial. Headers: dark blue. Input cells: blue text. Formula cells: black on light-grey fill.
* Rating bands are Low 1–4, Medium 5–9, High 10–16, Critical 17–25. If you propose different bands, update the formulas,
  the legend, the Dashboard and the README together.
* Mapping suggestions should reference the current editions: ISO/IEC 27001:2022, NIST CSF 2.0, ISO/IEC 42001:2023.

## Reporting a problem with the content

If you believe a mapping or clause reference is wrong, please open an issue quoting the sheet, cell and the
standard's text you are comparing against.
